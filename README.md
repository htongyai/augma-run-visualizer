# Augma Run Visualizer

Lumphini Park, Benjakitti Forest Park and the Green Mile bridge between them as a 3D digital twin, built from OpenStreetMap paths, buildings, landmarks and trees. Drop in a Strava or GPX run and it replays as a glowing runner with a red trail, km markers and a sun that follows the time of day, then exports straight to an Instagram Reel or Story.

**Try it live:** https://augmaimaginarium.com/run/
Part of **Augma Repo**, the free shelf of tools and studies from Augma Imaginarium: https://repo.augmaimaginarium.com

## Run it locally

It's a static web page. Serve this folder with any static server and open it in a browser:

```
npx serve .
```
